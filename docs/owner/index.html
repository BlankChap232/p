Connect your private dashboard

Your panel is built. It needs a private database to securely remember who you approve. Until connected, no approvals are active.

Privacy: Never enter a Supabase secret key or service-role key here. This page accepts only a publishable client key. Owner permissions are enforced by database rules.

Three simple setup steps

  1. Create a Supabase project. This gives your app a private cloud database for approvals. Open Supabase.
  2. Connect the project here. Copy its URL and publishable key from Project Settings → API Keys.
  3. Secure your owner account. Sign in by email. Use the included database setup to make only your account an owner.

The same app can later connect to this database to check access when someone launches Panda Tv Elite.

Owner sign-in

Enter your email. We'll send a one-time sign-in link through your Supabase project. A valid login alone is not enough: your account must also be on the owner allowlist.

If the email does not arrive, check Supabase Auth email settings. The project must allow redirects to this dashboard address.

How approvals work

Once the Android app is connected to this backend:

  1. A viewer signs in with their verified email.
  2. Panda Tv Elite checks your list.
  3. Only active, unexpired accounts are permitted to continue.
  4. Pausing or revoking a member blocks their next authorization check.

The existing 2.0.1 APK is not currently connected to this access database. No streaming changes are being made by this dashboard.
